API для приложений

Создавайте отдельные токены для внешних клиентов и управляйте доступом.

Управление токенами

Введите токен администратора из файла admin_token.txt в папке данных сервера. Токен приложения показывается один раз после создания.

Токен администратора остаётся только в открытой вкладке и не сохраняется браузером.

Как отправить запрос

Приложение передаёт свой токен один раз при запуске генерации. Для проверки конкретного задания используется его отдельный ключ.

POST /api/v1/generations Authorization: Bearer okai_ВАШ_ТОКЕН Content-Type: application/json {"prompt":"A snowy mountain at sunrise","model":"fast","duration":4,"ratio":"16:9"} GET /api/v1/generations/ID_ЗАДАНИЯ X-Request-Key: sk-КЛЮЧ_ИЗ_ОТВЕТА
